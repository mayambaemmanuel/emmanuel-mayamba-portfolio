# Emmanuel Mayamba — Portfolio Website

This folder contains the HTML and CSS files for Assignment 2.

## Before you submit

1. Open `index.html` and replace `your-email@example.com` with your own email address.
2. Copy `index.html` and `styles.css` into your existing Assignment 1 GitHub portfolio repository, replacing its matching files if necessary.
3. Commit and push the changes to GitHub.
4. Submit the link to that GitHub repository.

## Included requirements

- Semantic navigation, main sections, cards, and footer
- CSS colours, typography, spacing, borders, and shadows
- Grid and Flexbox layouts
- Responsive layouts for tablet and mobile screens
- Hover and keyboard focus states, transitions, animation, and reduced-motion support
